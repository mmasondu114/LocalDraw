# LocalDraw 本地漫画工作室

LocalDraw 是 Windows x64 桌面应用，支持创作漫画、编辑分镜，以及从每格提示词直接出图。

## 下载和安装

登录有仓库访问权限的 GitHub 账号。新电脑从[首次安装包](https://github.com/mmasondu114/LocalDraw/releases/tag/v0.1.1)安装，已有安装从[最新发行版](https://github.com/mmasondu114/LocalDraw/releases/latest)下载程序更新。

- **首次安装**　把四个以 `.001` 至 `.004` 结尾的文件和 `Join-LocalDraw-Setup.cmd` 下载到同一个文件夹。双击命令文件，等它确认安装程序校验通过，再运行合并得到的 EXE，选择空目录安装。此包面向 Windows x64、RTX 4080 环境。首次出图需要在应用中点「下载模型」，或使用已安装的模型。
- **更新已有安装**　打开或退出桌面工作室时，LocalDraw 会检查私有仓库的最新 GitHub 正式版，下载对应的 `Update.zip` 并验证 SHA-256。空闲时安装，正在出图、执行队列或下载模型时延后处理。程序更新保留个人作品、模型、LoRA 和本机运行配置。

## 绘图模型预加载与 ComfyUI 自动保活

顶部「绘图模型」默认开启 **ComfyUI 自动保活**：出图完成后不杀绘图进程，连续出图免去 30–40 秒重载等待；也可手动预加载指定底模、关闭保活或一键卸载并释放显存。启动分析模型或暂停生成时会自动释放显存。

更换同一底模下的角色、LoRA 或权重，直接修改下一次出图的设置即可；所有入口只要勾选了 LoRA 就会强制生效并自动记忆权重、补全触发词。新提示词和逐格导入会优先使用已保活/预加载的底模。逐格导入缺少编辑参考图，因此会跳过专用的 Qwen 编辑模型。

## 提示词出图

首页「提示词出图」点「开始画一张图」，直接输入正负提示词，选择角色、LoRA、模型、张数和可选种子（留空随机，填写后多张按序递增）即可出图。

出图后，右侧预览区右下角会出现「二采」按钮。点击后右侧图片保持原位，左侧切换为仅含二采参数的二级菜单，支持同模型或跨模型（如 Krea2 → Krea2 / MOSS / Anima）重绘、按当前二采底模隔离的 LoRA 选择、步数、重绘幅度、种子、缩放倍率（`1.0×` / `1.25×` / `1.4×` / `1.5×` / `2.0×`）、「细节重绘（潜空间 `bicubic`）/ 保真超分（`RealESRGAN`）」方式选择、实时目标尺寸与「自动 / 整图精修 / 分块高清」分块策略选择（超出模型整图舒适区时自动切分块逐块重绘并无缝羽化拼接）以及可选「二采后超分」（`RealESRGAN` `1.5× / 2.0×`，采样完成后锐化放大且不改脸型）；按 `Esc` 或左上角「← 返回」返回主界面。二采 1 张完成后自动应用，多张完成后在右侧缩略图中挑选并点击「应用这张二采图」，随时可点「取消应用」恢复一采原图（不会删除已生成的二采图）。

提示词出图和分镜出图共用紧凑布局。中栏顶部显示已选角色和 LoRA，可在 LoRA 名称旁直接改权重。点击下方搜索框查找并添加，支持名称、拼音和英文别名。上方任务进度铺满提示词区和中栏，右侧整列用于图片预览。

## 界面缩放与多屏适配

启动时按主屏分辨率和 Windows 缩放自动选择界面缩放：1080p@125% 笔记本为 90%，1080p@100%、2K@125%、3440×1440@125% 为 100%，2K 或 3440×1440 @100% 为 115%。也可以在顶部「外观」→「界面缩放」手动选 90%–150%，点「立即重启生效」。提示词出图页的输入栏和 LoRA 栏保持舒适宽度，屏幕越宽，多出来的宽度都给右侧图片预览；首页在 2K / 带鱼屏上改为「任务卡 | 最近作品」双栏。

## 从每格提示词开始

首页「分镜出图」点「创建分镜作品」。填写标题，可选填故事构想或期望的页数。点击「生成分镜」，本地分镜模型会规划每页画格、画面内容和比例。预览后点击「确认分镜并进入出图」。在正向提示词框粘贴带编号的单格 JSON，如 `{"id":"P001-K01","visual_prompt":"rainy train station","negative":"watermark"}`。工作室按编号定位并默认使用该格分镜比例。纯文字提示词可手选画格。角色、LoRA、张数和比例都可在提交前调整。

左边选择画格，右侧预览随之切换。右下角的「上一格」「下一格」按分镜顺序跨页切换。「上一张」「下一张」可以查看同一格的不同候选图。

在候选图下点「采用到 P001-K01」，这张图就成为该格的选图。采用同格的另一张会替换选图，「取消采用」保留候选原图。「整图修改」会列出尚缺的格子；全部采用后，可调整各页版式及裁切方式，生成并下载整页 PNG。

在首页点「直接导入每格提示词」，粘贴内容后点「导入并设置出图」。在设置页选择角色、LoRA 和默认张数，也可以填写通用负面提示词。展开「逐格编辑负面提示词和张数」可以修改某一格。生成时会将通用负面提示词追加在本格负面提示词之后。点「开始生成」提交任务，选「稍后再画」可以从作品旁的「出图设置」继续。

使用 Anima Delta v6 和 AnimeEditV2、且本次至少有两格时，设置页默认勾选「自动参考上一格」。第 1 格独立生成。后续每格使用上一格在本次任务中最先成功生成的图片作为参考，跨页也会接续。取消勾选即可让各格独立生成。

逐格 JSON 的一页一格示例：

```json
[{"id":"P001-K01","visual_prompt":"雨夜街口，远景","negative":"水印，多余文字"}]
```

在「提示词出图」和「融合任务」逐格审核中，勾选「正负面同框（JSON）」即可在同一个框中编辑 `visual_prompt` 和 `negative`。「复制本格 JSON」会复制可直接导入的一格。在「直接导入每格提示词」中可复制给 AI 的格式要求；在「逐格出图设置」中可复制全部画格，含当前编辑的负面词和通用负面词。

## 融合任务

在首页或「夜间任务列表」点「融合任务」，依次添加至少两部已有分镜的作品或队列任务。用「上移」「下移」决定拼接顺序，再逐格核对正面和负面提示词。可以跳过不想画的格子，再用「恢复此格」取回。改过的画格需要重新点「通过并继续」。点「稍后继续」会在当前浏览器保留审核进度。逐格审核完后点「保存融合任务并设置出图」，会创建独立的新作品，并进入角色、LoRA、张数和连续参考设置。新作品使用审核过的提示词重新出图，原作品和队列任务可照常使用。

## 检测更新

桌面自动更新使用本机 GitHub CLI 的登录状态或 `GH_TOKEN`，需要此仓库的读取权限。打开「检测更新」可查看最近一次自动更新的状态，也可以使用一次性的只读令牌手动查询。网络不可用时可继续使用已安装版本。更新涉及正在使用的启动器时，会等窗口关闭后安装。

## 源码与变更记录

`src/comic_workflow` 是纯进程内核心（62 个业务模块，含 `app_core.py` 控制器），`src/comic_workflow/qt_app` 是原生 PySide6 桌面界面（10 个模块，暖麻默认 + 青黛经典主题，零 Web/HTTP/WebView2 依赖），`scripts/windows/StudioLauncher.cs` 是纯原生桌面启动器源码。开发环境使用 Python 3.12 + PySide6，在 `LocalDraw/` 目录下通过 `PYTHONPATH=src` 运行 `tests/` 离线测试，或运行 `LocalDraw.exe --self-test` 做桌面自检。

完整目录索引、开发规范与每次代码变更记录请统一查看根目录 [`../README.md`](../README.md) 与 [`../docs/CHANGELOG.md`](../docs/CHANGELOG.md)。所有后续修改须同步记录在根目录 README 或其指引的变更日志中。
