# LocalDraw 本地漫画工作室

LocalDraw 是 Windows x64 桌面应用，支持创作漫画、编辑分镜，以及从每格提示词直接出图。

## 下载和安装

登录有仓库访问权限的 GitHub 账号。新电脑从[首次安装包](https://github.com/mmasondu114/LocalDraw/releases/tag/v0.1.1)安装，已有安装从[最新发行版](https://github.com/mmasondu114/LocalDraw/releases/latest)下载程序更新。

- **首次安装**　把四个以 `.001` 至 `.004` 结尾的文件和 `Join-LocalDraw-Setup.cmd` 下载到同一个文件夹。双击命令文件，等它确认安装程序校验通过，再运行合并得到的 EXE，选择空目录安装。此包面向 Windows x64、RTX 4080 环境。首次出图需要在应用中点「下载模型」，或使用已安装的模型。
- **更新已有安装**　等当前任务结束后关闭工作室，将对应版本的 `Update.zip` 解压到含有 `LocalDraw.exe` 的目录并覆盖程序文件。重启电脑后打开工作室，以加载新的后台程序。此更新包适用于已安装 RTX 4080 完整版的电脑。

## 预加载绘图模型

顶部「绘图模型」可选择已安装的底模并提前加载。连续使用同一底模出图时工作室会保留绘图服务。再次选中已加载的模型可卸载并释放显存，选中其他模型可切换。启动分析模型或暂停生成时会释放预加载。

更换同一底模下的角色、LoRA 或权重，直接修改下一次出图的设置即可。新提示词和逐格导入会优先使用已预加载的底模。逐格导入缺少编辑参考图，因此会跳过专用的 Qwen 编辑模型。

## 提示词出图

首页「提示词出图」点「开始画一张图」，直接输入正负提示词，选择角色、LoRA、模型和张数即可出图。

提示词出图和分镜出图共用紧凑布局。中栏顶部显示已选角色和 LoRA，可在 LoRA 名称旁直接改权重。点击下方搜索框查找并添加，支持名称、拼音和英文别名。上方任务进度铺满提示词区和中栏，右侧整列用于图片预览。

## 从每格提示词开始

首页「分镜出图」点「创建分镜作品」。填写标题，可选填故事构想或期望的页数。点击「生成分镜」，本地分镜模型会规划每页画格、画面内容和比例。预览后点击「确认分镜并进入出图」。在正向提示词框粘贴带编号的单格 JSON，如 `{"id":"P001-K01","visual_prompt":"rainy train station","negative":"watermark"}`。工作室按编号定位并默认使用该格分镜比例。纯文字提示词可手选画格。角色、LoRA、张数和比例都可在提交前调整。

左边选择画格，右侧预览随之切换。右下角的「上一格」「下一格」按分镜顺序跨页切换。「上一张」「下一张」可以查看同一格的不同候选图。

在候选图下点「采用到 P001-K01」，这张图就成为该格的选图。采用同格的另一张会替换选图，「取消采用」保留候选原图。「整图修改」会列出尚缺的格子；全部采用后，可调整各页版式及裁切方式，生成并下载整页 PNG。

在首页点「直接导入每格提示词」，粘贴内容后点「导入并设置出图」。在设置页选择角色、LoRA 和默认张数，也可以填写通用负面提示词。展开「逐格编辑负面提示词和张数」可以修改某一格。生成时会将通用负面提示词追加在本格负面提示词之后。点「开始生成」提交任务，选「稍后再画」可以从作品旁的「出图设置」继续。

使用 Anima Delta v6 和 AnimeEditV2、且本次至少有两格时，设置页默认勾选「自动参考上一格」。第 1 格独立生成。后续每格使用上一格在本次任务中最先成功生成的图片作为参考，跨页也会接续。取消勾选即可让各格独立生成。

逐格 JSON 的一页一格示例：

```json
[{"id":"P001-K01","visual_prompt":"雨夜街口，远景","negative":"水印，多余文字"}]
```

在「提示词出图」和「融合任务」逐格审核中，勾选「正负面同框（JSON）」即可在同一个框中编辑 `visual_prompt` 和 `negative`。「复制本格 JSON」会复制可直接导入的一格。在「直接导入每格提示词」中可复制给 AI 的格式要求；在「逐格出图设置」中可复制全部画格，含当前编辑的负面词和通用负面词。

## 融合任务

在首页或「夜间任务列表」点「融合任务」，依次添加至少两部已有分镜的作品或队列任务。用「上移」「下移」决定拼接顺序，再逐格核对正面和负面提示词。可以跳过不想画的格子，再用「恢复此格」取回。改过的画格需要重新点「通过并继续」。点「稍后继续」会在当前浏览器保留审核进度。逐格审核完后点「保存融合任务并设置出图」，会创建独立的新作品，并进入角色、LoRA、张数和连续参考设置。新作品使用审核过的提示词重新出图，原作品和队列任务可照常使用。

## 检测更新

点击窗口顶部的「检测更新」。工作室将当前版本与私有仓库的最新正式发行版比较。本机已登录的 GitHub CLI（在 PATH 中）或 `GH_TOKEN` 可用于查询。也可以在弹窗里填写此仓库具有 Contents 只读权限的 GitHub 令牌，令牌仅用于本次查询。「打开 GitHub 下载页」使用系统浏览器里的 GitHub 登录状态。

## 源码与运行环境

`src/comic_workflow` 是本地服务，`web` 是界面，`scripts/windows` 包含桌面启动器源代码。安装包提供配套的 Python、绘图运行时和桌面组件。可在已安装的运行环境中替换源码进行开发。开发环境使用 Python 3.12，通过 `PYTHONPATH=src` 运行对应测试。
