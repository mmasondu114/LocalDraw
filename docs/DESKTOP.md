# Local Draw 桌面版

双击项目根目录的 `LocalDraw.exe`。原生窗口默认最大化，首页上方可直接写故事。下方的作品卡片显示标题和分镜页数，点一下即可继续创作，上次打开的漫画排在最前。「打开作品」可以按名称搜索全部漫画。现有作品和模型继续使用原目录。

## 创作

1. 在故事框输入原文，点击「生成 POV 分镜」。
2. 阅读分镜，点击「确认并导出分镜」选择 JSON 文件的保存位置。
3. 逐格编辑正负提示词，或点击「导入提示词」载入填好的 JSON。每格可生成 1–16 张候选图，默认 8 张。
4. 数字 1–8 选图，左右箭头翻格，Enter 向后翻格，↓ 标记问题并聚焦说明框。问题框内 Enter 保存并继续，Shift + Enter 换行。提示词框内 Esc 返回审图。
5. 最后一格继续向后进入问题汇总。可以修改说明、解除标记，或按说明统一重画。

「打开作品」列出已有漫画。图片和选图沿用 `data/projects`。桌面输入草稿、上次审图位置和待查看的任务编号保存在 `data/native-editor`。已有任务在关闭桌面窗口后继续运行。

在 3440×1440 屏幕上，逐格绘图从左到右排列创作导航、分镜目录、画面和本格绘图工具。点击目录可以跳格，画面下方是候选图，右侧可以查看分镜与对白、导入提示词或导出分镜。缩小窗口时提示词移动到画面下方。右上角「界面显示」可以切换并记住字号。在创作首页点「返回刚才的工作台」可以继续刚才那一格。

## 构建与验证

运行 `scripts/build_launcher.ps1` 编译根目录的 `LocalDraw.exe`。构建使用 Windows 自带的 .NET Framework 4.x 编译器、Windows Forms 和项目图标。

运行 `scripts/test_desktop_ui.ps1` 在临时作品中通过实际 EXE 验证故事、分镜导出、提示词、选图快捷键和问题重画。测试用固定结果代替模型推理。`LocalDraw.exe --self-test` 仅检查原生窗口与输入控件并退出。
