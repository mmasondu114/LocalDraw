# 彩色叙事漫画方向

用户目标：接近《明日方舟》官方漫画的人物比例、线条和叙事感，同时保留精致彩色日漫的上色。用户现已明确认可画风对照中间列（底模＋方舟样式 LoRA 0.7），当前作品以此为默认。该认可针对样图画风，不代表之前剧情图的内容已合格。

参考：[官方《莱茵生命》正文](https://comic.hypergryph.com/terra-historicus/comic/1421/episode/7424)。已在浏览器实际查看正文；该篇采用黑白线稿与网点，因此“细腻彩色”是用户要求的延伸，不称作原作已有的配色。

- 人物：成年比例、自然五官和表情，避免大头娃娃感；博士遵守完全遮脸的角色资料。
- 线条：清楚、细致，有轻重变化；减少粗黑描边和塑料般高光。
- 色彩：克制饱和度，明暗服务于场景，避免无依据的霓虹光。
- 构图：表现当格动作与人物关系；特写不堆全身特征，六张候选不能改变原文锁定的视角。
- 质量：自动审核只辅助核对内容，不能替用户决定画面是否好看。

## 小样与限制

2026-09-18 用 Animagine XL 4.0 Opt 做两组同种子消融对照：底模 / 底模加用户 LoRA 0.7 / 再加原全身参考 0.7。实际图片保存在 `data/test-results/art-style/20260918-145804-389075`，网页第三步“查看画风对照”可查看。样本中加入 LoRA 未出现明显整体崩坏，参考图明显改变取景、比例和色彩；不能由六张图推断 LoRA 对所有情节都无问题，也不能证明底模达到目标风格。

新增按镜头保留可见外观、手部镜头跳过全身参考、参考权重上限 0.3、镜头约束、构图草图控制和框选局部修复。完整角色卡仍独立保存。

构图草图是模型输出的简易几何轮廓，不是画师草稿。首轮实际对照出现人物漏画、发色和服装串位；ControlNet 能运行不等于构图成功。因此仅在“小样对照”中显式启用，普通重画默认关闭，避免把未经视觉验收的草图强加到所有画格。没有更换用户默认底模或 LoRA 选择，也没有重新启动整部批量制作。
